# What is this?
This is a [PopTracker](https://github.com/black-sliver/PopTracker) pack for Silvris' [Mega Man 4 integration](https://github.com/Silvris/Archipelago/releases?q=mega+man+4&expanded=true) for [Archipelago](https://github.com/ArchipelagoMW/Archipelago).

It tracks the items that the player receives and the locations that the player checks, displaying which ones are reachable based on their items.

It features fully-fledged autotracking for items and locations by connecting to the server and reading the data from the player's slot.

It also has segmented maps displaying the game's stages and where all of the pickups are located.

# Limitations
Currently, most options do not autotrack, and you will have to set them manually. **The only option that autotracks is `consumables`.**
As a result of this, if you have `jammed_buster` turned off, then you will have to manually enable the Charge Buster item if you want it to display as received.

While the maps have been styled in a way that is reminiscent of other PopTracker packs that support autotabbing, that feature is *not* present in this pack.

If you have boss weakness randomization on, any boss locations that you can reach but are not guaranteed to be able to defeat will be colored **blue**.
This does not interact perfectly with other functions and may result in logic being unclear.

# AI Policy
**No** AI was used intentionally for any part of the creation of this pack.
AI was **not** used for code, art assets, consultation, or anything else.

Most of the JSON files and some LUA files were written by hand; the remainder were autogenerated by the [poptracker-pack-builder](https://github.com/StripesOO7/poptracker-pack-builder). All of these files have had their contents checked.

Resources used for references **may have** used AI, subject to their own policies.

PRs that are known or strongly suspected to have used made significant use of AI will be categorically denied.

"Significant" use is primarily in using AI to write any part of the code. Using it as a reference exclusively is usually within acceptable parameters. Anything else will be determined on a case-by-case basis.

If a contribution that made use of AI is later discovered to have been disingenous about the extent of its use (including saying that the contribution made 0 use of AI), efforts will be taken immediately to expunge the related code, and the contributor will henceforth be blocked from making any further contributions to the repository.
