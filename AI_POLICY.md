**No** AI was used intentionally for any part of the creation of this pack.
AI was **not** used for code, art assets, consultation, or anything else.

With exception to many of the LUA files, all of the code has been written by hand.
Most of the LUA files were generated by the [poptracker-pack-builder](https://github.com/StripesOO7/poptracker-pack-builder), with only a handful being written or modified by myself.

Resources used for references **may have** used AI, subject to their own policies (and age). See the README for a list of these references.

PRs that are known or strongly suspected to have used made significant use of AI will be categorically denied.

"Significant" use is primarily in using AI to write any part of the code. Using it as a reference exclusively is usually within acceptable parameters. Anything else will be determined on a case-by-case basis.

If a contribution that made use of AI is later discovered to have been disingenous about the extent of its use (including saying that the contribution made 0 use of AI), efforts will be taken immediately to expunge the related code, and the contributor will henceforth be blocked from making any further contributions to the repository.
